## Setup
1. Install VS Code and the **Live Server** extension.
2. Open this folder in VS Code.
3. Right-click `books.html` and choose **Open with Live Server** (do not open it with `file://`, or `fetch()` will fail).
4. `jquery-dom.html` also needs an internet connection to load jQuery from `code.jquery.com`.
